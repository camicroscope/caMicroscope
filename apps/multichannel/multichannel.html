Upload Multichannel / OME-TIFF Slide

Steps for uploading.

  1. Select a single-file OME-TIFF (or a .zip containing exactly one) with all channels embedded in one physical file.
  2. Enter the desired filename and a slide name.
  3. Click Preview Slide to check it, then Finish Upload to register it.
  4. Once registered, a link to view it (already set up for multichannel viewing) will appear below.

Not supported yet: raw unstitched multi-panel acquisitions (need a stitching pipeline like ASHLAR/MCMICRO first) and multi-file-per-channel datasets (e.g. one physical file per channel) -- both are detected and flagged rather than silently mis-registered.
